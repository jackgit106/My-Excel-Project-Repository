# My-Excel-Project-Repository
# Excel Retail & Sales Data Analysis

## Project Overview

This project was completed as part of a **Data Technician Bootcamp** and focused on analysing retail and sales data using **Microsoft Excel**.

The project involved cleaning, organising, analysing, and visualising data to identify useful business insights and trends.

## Skills & Techniques

- **Excel formulas:** `SUM`, `SUMIF`, `AVERAGE`, `AVERAGEIF`, `DATE`, `MONTH`, `YEAR`, `UNIQUE`, and `VLOOKUP`
- **Data filtering and sorting** to explore specific products, categories, dates, and sales results
- **PivotTables** to summarise and analyse large datasets efficiently
- **SWITCH function** to create conditional classifications and improve data analysis
- **Charts and visualisations** to communicate sales performance and trends
- **Data organisation and preparation** for effective analysis and reporting

## Key Tasks

- Calculated total and conditional sales using `SUM` and `SUMIF`
- Analysed average sales and performance using `AVERAGE` and `AVERAGEIF`
- Extracted and manipulated date information using `DATE`, `MONTH`, and `YEAR`
- Identified unique values using `UNIQUE`
- Retrieved related information from datasets using `VLOOKUP`
- Used filtering and sorting to investigate specific areas of the retail data
- Built PivotTables to summarise sales and identify patterns
- Applied `SWITCH` to categorise and interpret data
- Created charts to present findings clearly and support data-driven insights

## Outcome

The project strengthened my practical Excel and data analysis skills, demonstrating how spreadsheet tools can be used to transform raw **retail and sales data into meaningful insights and visual reports**.
